LOCAL LAB

LinkUp Pentest Lab Directory

A multi-page social application and API target for practicing the four-week Web Application & API Penetration Test curriculum. Use a local browser and Burp Suite against this app.

Local practice only. The server binds to 127.0.0.1. SSRF targets an in-process mock service, file reads use a virtual catalog, uploads stay in memory, and command injection is simulated without starting an operating-system process.

Exercise and endpoint map

Error-based SQL injection

Search input is interpolated into SQLite queries and database errors are exposed.

GET /api/search?q=... · GET /api/labs/sql?username=...

Stored and reflected XSS

Post/comment content is stored and rendered in the feed; a separate page reflects its query.

POST /api/posts · POST /api/posts/:id/comments · /lab/reflected?q=...

Open redirect

Redirect destination is accepted without validation.

GET /go?to=...

SSRF mock service

Exercises internal-resource access against fixed in-process mock routes.

GET /api/labs/ssrf?url=http://mock.internal/status

File upload

Accepts arbitrary file names and types into volatile memory with a 5 MB size limit.

POST /api/labs/upload · GET /api/labs/upload · GET /api/labs/upload/:id

Path traversal and LFI

File lookup and template inclusion are limited to the virtual training catalog.

GET /api/labs/files?path=... · GET /api/labs/include?page=...

Simulated OS command injection

Shell separators and a small command set are interpreted in memory; no shell is invoked.

GET /api/labs/command?name=...

IDOR / BOLA

Object identifiers expose synthetic profile details without ownership checks.

GET /api/users · GET /api/users/:id · GET /api/users/:id/posts

Authentication and session handling

Demo credentials, weak password handling, predictable script-readable session cookies, and unauthenticated API surfaces.

POST /api/auth/login · POST /api/auth/register · GET /api/auth/me · POST /api/auth/logout

SQL injection in lab authentication

A separate synthetic login query interpolates both fields and returns verbose SQLite errors.

GET /api/labs/auth-sqli?username=…&password=…

CSRF state change

Cookie-authenticated profile change uses a state-changing GET without a CSRF token.

GET /api/labs/csrf/profile?bio=…

Unsigned JWT validation

The training verifier trusts a decoded JWT payload without checking its signature or expiry.

GET /api/labs/jwt/issue · GET /api/labs/jwt/me

Checkout business logic and order BOLA

Checkout trusts client-supplied price and quantity; synthetic orders are retrievable without ownership checks.

GET /api/labs/shop/products · POST /api/labs/shop/checkout · GET /api/labs/shop/orders/:id

Admin moderation

Admin-only user management plus post deletion and virtual comments/likes attributed to a selected demo account.

/api/admin/* · Sign in with admin / admin123

Demo accounts and reset
